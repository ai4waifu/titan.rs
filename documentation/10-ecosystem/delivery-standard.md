# 统一交付标准

每个领域模型都必须交付以下闭环：

1. 数据格式、schema、许可和完整性检查。
2. 确定性的预处理、采样、batch 和 feature/token 转换。
3. 使用 `#[neural]` 与 `#[parameters]` 的模型定义及稳定参数 key。
4. 训练配置、optimizer、精度、梯度和分布式策略。
5. 验证/评估指标、基线输入和容差。
6. checkpoint 保存、恢复和跨拓扑验证。
7. 单机推理、batch/streaming 状态和资源预算。
8. Native 部署 manifest、能力检查和最小服务模板。
9. profiler 标识、领域指标和 `tt debug` 诊断。
10. 数值、属性、故障、性能和兼容性测试。

## 完整性门槛

只提供算子集合、模型结构或论文配置不能算作领域交付。模型必须从原始或标准化数据开始，经过训练/加载、评估、保存、恢复和部署，且全部使用公共 runtime 与 ArtifactStore。

## 基准记录

报告硬件、驱动、backend、模型/权重摘要、输入、batch、精度、上下文/分辨率、并发、warmup、样本数、统计方法、峰值内存和失败率。领域之间不以不同输入的单一吞吐数字比较。
