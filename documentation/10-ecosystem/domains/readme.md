# 领域目录

七个领域共享 Titan.rs 基础设施，但各自维护数据语义、任务指标和领域特定组件。

- [视觉](vision.md)：图像、视频、空间输入和边缘部署。
- [语言与生成式模型](language.md)：tokenizer、Transformer、生成、KV Cache 和分层执行。
- [推荐系统](recommendation.md)：稀疏特征、Embedding、检索和在线更新。
- [强化学习](reinforcement.md)：环境、采样、回放、Actor-Learner 和确定性。
- [时间序列](forecasting.md)：规则/不规则采样、统计模型、神经模型和在线预测。
- [音频与语音](audio.md)：频域变换、流式音频、识别和合成。
- [图学习](graph.md)：稀疏图、邻居采样、消息传递和图分区。
