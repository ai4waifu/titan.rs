# 产品定位

Titan.rs 是 Rust 原生的训练与推理基础设施。它将数学表达式、自动微分、图编译、内核生成、设备执行、分布式训练、自动调优、checkpoint、遥测和部署组织为一条可验证的执行链。

## 目标

- 模型代码接近数学公式，后端细节不泄漏到业务层。
- 从单 CPU 到多节点 GPU 使用同一模型和训练语义。
- 训练与推理均可编译、可观测、可恢复、可部署。
- 在不引入 C++ 深度学习运行时的前提下使用设备驱动能力。
- 通过所有权、类型系统和版本协议消除资源与工件歧义。
- 通过生产遥测持续改进 kernel 和执行计划选择。

## 非目标

- 不把 Python 作为部署或运行时依赖。
- 不把 Web 浏览器作为大模型主要执行环境。
- 不允许用户手工管理设备裸指针、stream 生命周期和 collective 顺序。
- 不以宏生成特殊公式代替通用自动微分。
- 不以 target 名称、策略枚举或描述性 IR 代表能力已经完成。
- 不让自动调优改变算子数值语义、梯度语义或确定性承诺。

## 成功标准

最终系统必须满足：

1. 用户可用自然 Rust 表达完整训练公式。
2. 任意可微模型可由通用 backward graph 求梯度。
3. CPU 与至少两个 GPU 后端共享数值与错误语义。
4. 图编译器可以解释每个优化和内存决策。
5. 多节点失败能够产生有界错误并从一致 checkpoint 恢复。
6. 每个性能选择可以追溯到设备、kernel、shape、layout 和测量证据。
7. 运行过程可以由 `tt.exe` 和 Web UI 完整诊断。
8. 所有持久化工件具有明确版本、校验、兼容和迁移策略。
