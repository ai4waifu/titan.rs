# 超显存模型与 MoE 分层执行

本目录定义权重规模超过单设备显存时的执行协议。系统通过分层存储、显式资源预算、权重放置、按需迁移、预取和回退扩大可运行模型规模，但每次运行是否可行必须由模型格式、设备能力、主机内存、存储带宽、上下文长度、并发和延迟目标共同验证。

## 执行目标

给定模型、量化格式、上下文长度、并发数、设备、主机内存和存储吞吐，Planner 必须在执行前回答：是否满足硬资源约束、预计首 token 延迟、预计稳态吞吐、关键瓶颈、回退路径以及不可满足的原因。

权重远大于显存时，性能可能受设备互连、PCIe、主机内存或持久化存储带宽限制。执行计划和观测数据必须呈现真实瓶颈，不允许用模型文件可读取代替可服务性验收。
