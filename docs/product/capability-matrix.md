# 能力矩阵规则

能力声明必须由 schema registry、backend registry、capability predicate、测试结果和 benchmark artifact 共同决定。crate 存在、枚举存在、README 文本、mock driver、placeholder compiler、source string 或 host reference 都不能构成支持证据。

状态只允许 `verified`、`discoverable`、`skipped_no_driver`、`unsupported`。具体矩阵见自动生成的 `docs/backend-support.generated.md`。
